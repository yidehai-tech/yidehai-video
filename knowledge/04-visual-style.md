# 亿德海视觉风格与 OpenMotion 出片规范

> 用于统一全员产出的视频观感，无论通过 OpenMotion MCP、剪映还是其他工具制作，均遵循本规范。

---

## 一、画幅与平台安全区（9:16 竖屏）

- **标准分辨率**：`720×1280` 或 `1080×1920`（9:16 竖屏，24–30 fps）。
- **四边安全区（防止被抖音/视频号/小红书 UI 遮挡）**：
  - 顶部留白：≥ 12%（避开状态栏与搜索框）；
  - 底部留白：≥ 20%（避开账号名、文案区与进度条）；
  - 右侧留白：≥ 14%（避开点赞/评论/转发图标列）；
  - 左侧留白：≥ 6%。
- **排版层级**：
  - **顶部固定双行大标题**（上方安全区内）：概括本条核心痛点/利益点，字号醒目；
  - **中景主视觉**：实拍画面 / 动效信息卡 / 对比清单 / 关键词弹出；
  - **中下部主字幕**：每行 ≤ 15 字，重点关键词高亮（品牌暖黄）；
  - **干净利落收尾**：**不放底部品牌浮条、不做全屏静态尾卡**，话音/画面一落立刻结束，保持原生 UGC 观感与高完播率。

---

## 二、品牌配色建议（清爽环保 + 信任感）

提供两套已验证的高可读配色方案，按题材选用：

1. **深绿质感风（适合干货/避坑/大字报/数据对比）**
   - 背景主色：深森林绿 `#102A22` / `#14362B`
   - 主文字色：纯净白 `#FFFFFF`
   - 强调高亮色：暖明黄 `#FFD43B`（用于数字、感觉词、核心卖点）
   - 辅助标签/胶囊：清浅绿 `#2F9E44` 或半透明深色底 `rgba(0,0,0,0.55)`
2. **米白生活风（适合居家整理/宝妈/换季清单）**
   - 背景主色：暖米白 `#F7F5EE`
   - 主文字色：深墨绿 `#163026`
   - 强调高亮色：活力橙 `#E8590C` 或品牌绿 `#2B8A3E`

### 2.1 批量出片配色硬规则（v2.3.2 新增 · 违反即判不合格）

- **批量 ≥3 条必须轮换配色**：相邻两条主色相不同，整批不得全部命中同一套配色。
- **深森林绿 `#102A22` 只作插画色块 / 深色胶囊，不得作整屏背景连续出现**。实测整批 5 条全用深绿 + 暖黄，会让手机小屏发闷、观感压抑（真实用户反馈：「绿色颜色太深了不舒服」「怎么都是一个绿色和黄色」）。
- 居家整理 / 换季 / 宝妈 / 衣柜类选题**默认米白生活风**；避坑干货类可少量穿插深绿质感风，**每批至多 1 条**。
- 暖明黄 `#FFD43B` 只作数字 / 单点高亮，不得与深绿一起铺满整批。

## 三、调用 OpenMotion 时的动效约束

使用任意支持 MCP/终端的 Agent（如 WorkBuddy、Claude Code、Codex、Cursor、Antigravity 等）调用 `OpenMotion` 生成视频时，在指令中固定附带以下约束：
1. **节奏明快**：每屏停留 **2.0–3.2 秒**，前 3 秒必须有强视觉变化（关键词放大弹入 / 痛点清单逐项划掉 / 对比数字跳动），绝不静态干晾。
2. **中文可读性优先**：使用清晰无衬线中文字体（思源黑体 / 苹方 / 微软雅黑粗体），禁用花哨手写体或细字体；字幕加轻微描边或深色半透明底衬，确保在任何画面上清晰可读。
3. **无乱码、无多余英文装饰**：画面内不出现无意义英文占位符或随机水印。
4. **利落收尾（无浮条无尾卡）**：话音/信息结束即收尾，不追加静态全屏片尾，也不叠加底部品牌浮条。
5. **默认有声（v2.3.2 新增）**：动效片默认出「中文旁白 + 真实无版权 BGM 12%」有声版，并保留同配色无声版供平台挂载音乐；合成参数见 `09-motion-batch-field-notes.md` 第三节。

## 四、双封面文字规范

每条视频必须准备同一套核心标题的**两个裁切版本**：
- **9:16 竖版封面**（1080×1920）：用于抖音、快手、视频号、百度、支付宝；
- **3:4 封面**（1080×1440）：用于小红书，确保核心两行大字严格居中在中间 60% 区域内，不贴边、不被裁切。

封面文字模板（3 层结构）：
- 顶部小徽章：`亿德海 · 专人免费上门回收`
- 中央两行大字（每行 6–9 字）：
  - 第 1 行（钩子/情绪）：如 `旧羽绒服别压箱底！`
  - 第 2 行（利益/反差）：如 `3件起收·免费上门`
- 底部辅助胶囊：`专人免费上门 · 按订单流程结算`

## 五、大字报视频（Poster）专项模板规范（1:1 对齐真实日更成品）

亿德海日常高频发布的「大字报视频」采用的是 **“8–9 秒风景空镜 + 单屏一镜到底大字报”** 爆款结构（利用阅读时长 12–15 秒 > 视频时长 8.8 秒，天然拉高完播率与复播率），**不要做成 4–6 屏来回翻页的 PPT**：

1. **规格与节奏**：
   - 画幅：`1080×1920`（9:16 竖屏），`30 fps`，总时长固定 **8.5–9.0 秒**（标杆为 `8.8s`）；
   - **背景**：一整段 **治愈系自然风景 / 慢动作实拍空镜视频**（如航拍山脊、草原山坡、微风花枝、蓝天绿叶、阳光树林草坪等），画面持续缓慢流动，叠加轻微暗角保证文字清晰；
   - **全片单屏不翻页**：开场第 0.1 秒全部文字即清晰呈现（或极轻柔整块淡入，绝不做长淡入留白）。

2. **四段式居中排版（严格从上到下，1:1 复刻）**：
   - **① 顶部超大主标题**（1–2 行，共 **8–16 字**）：居中粗体 + 深黑描边（3–4px）；下方紧跟一条 **细装饰横线 + 正中一个小圆点**（与标题同色）。
   - **② 中部正文大字报**（**80–120 字**，居中排 **8–12 行**，每行约 8–14 字，避免出现 1–2 个孤字换行）：纯白色 `#FFFFFF` 粗体 + 黑色描边（2.5–3px），行距紧凑舒适；语气像**朋友聊天 / 生活洞察 / 反常识干货**，前 70% 聊痛点共鸣，最后 2 句自然带出旧衣回收，绝不写成硬广。
   - **③ 底部轻互动问句**（1–2 行，字号比正文略小，与顶部主标题同色 + 黑描边）：用自然提问引发评论区讨论（如「这三个时机，你通常赶哪个？」「你踩过哪类的坑？」），**绝不写“评论区扣 1 / 关注我”等违规诱导词**。
   - **④ 最底部半透明圆角胶囊条**：深灰半透明圆角底 `rgba(0,0,0,0.52)` + 暖黄/白色小字，固定放在底部安全区上方：
     - 平台合规安全版（默认）：`亿德海 · 5公斤起专人免费上门`
     - *（注：历史实发模板中曾使用过「5公斤起免费上门，点头像预约」，因部分平台对「点头像」有引流限流风险，默认先出合规安全版，如需按特定账号口径调整由同事自行确认替换。）*

3. **三套已验证大字报配色（主标题 + 分隔线 + 问句同色，正文统一纯白黑描边）**：
   - **暖阳黄（最通用，配山川/草原/树林空镜）**：`#F5C842`
   - **薰衣草紫（适合女性衣柜/穿搭盘点，配蓝天/花枝/绿叶空镜）**：`#C9B6FF`
   - **暖米金（适合秋冬降温/治愈系阳光草坪空镜）**：`#F4E29C`

4. **音频与一鱼多吃**：
   - 默认配 8–9 秒**真实无版权**轻柔纯音乐（音量约 12%）；成员明确说「无声版」或需改挂平台热门治愈轻音乐时，才导出同款无声版，并在交付说明中写明（详见 `01-brand-rules.md` 第三节）；
   - 同一套四段式文案可顺手导出为小红书 3:4 图文首图，一鱼两吃。
